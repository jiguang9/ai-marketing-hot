# 输出格式模板（Output Formats）

---

## 模式 4：周报（weekly）

**触发词**：最近一周、本周 AI 营销、7 天热点

与日报格式相同，时间范围扩展到 7 天，「立即关注」部分最多展示 10 条。

---

## 通用规范

1. **语言**：全部中文，专有名词保留英文（如 ROAS、AEO、Performance Max）
2. **格式**：GitHub Flavored Markdown
3. **摘要截断**：原始摘要超过 200 字时截断并加 `…`
4. **时间格式**：优先使用相对时间（2 小时前），附绝对时间（北京时间）
5. **不暴露**：API 路径、脚本参数、技术调用细节、评分计算公式
6. **数量上限**：立即关注 ≤ 8 条，本周跟进 ≤ 6 条，保持观察 ≤ 4 条（防止信息过载）
7. **行动清单**：只列高优先级项的行动，≤ 5 条，使用 checkbox 格式 `- [ ]`
8. **适合谁**：每条热点必填，从以下标签中选 1-3 个：
   投放团队 / SEO 团队 / 内容团队 / 社媒团队 / 电商团队 / 出海团队 /
   品牌方 / B2B SaaS / 运营团队 / 营销总监 / CMO / 所有营销团队

## 数据缺失处理

| 场景 | 处理方式 |
|------|---------|
| 所有源获取失败 | 报告顶部显示警告，基于模型知识生成参考性简报 |
| 部分源失败 | 注明失败源，继续处理可用数据 |
| 当日无高分热点 | 一句话总览说明"市场相对平静"，降级展示中低优先级内容 |
| 时间窗内无数据 | 建议用户扩大时间范围 |
